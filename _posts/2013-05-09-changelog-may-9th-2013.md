Oh hey, didn't see you there. If you haven't noticed over the past week, we've pushed some updates:

* Live chat in collaborative code editing mode
* Fullscreen mode on the code editor
* Ability to remove collaborators from a box
* Added HAML support to the IDE
* Improved Mouse support in IDE console
* Scalable text rendering & improved color rendering in console
* Improved platform performance (faster provisioning)
* Miscellaneous IDE improvements

If you have any questions or suggestions, you can [talk to a human here](mailto:feedback@nitrous.io)

Don't forget to follow us on [Twitter](http://twitter.com/nitrousio) and
subscribe to our [Updates blog](http://feeds.feedburner.com/actionio-updates) to keep track
of changes.
