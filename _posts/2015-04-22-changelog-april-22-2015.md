---

The wait is over and Nitrous Pro has arrived! This is only the beginning as more features are yet to come. Follow [@nitrousio](http://www.twitter.com/nitrousio) for more news, or check out our [blog](http://blog.nitrous.io).

* Your dev environment just leveled up. Experience the new Nitrous which you have been waiting for. [Read the blog post for the full run down on new features, benefits, and pricing](http://blog.nitrous.io/2015/04/22/introducing-nitrous-pro.html).
* The pricing plan is designed to save you money. Only pay for the resources you use. Take a look at the new pricing page.
* Each plan includes your own dedicated resources for best performance.
* Collaboration has been completely rebuilt. You can collaborate on any file instantly with a partner by simply opening the file within the IDE editor. [Read our support guide for a full walkthrough](http://docs.nitrous.io/v1.0/docs/collaboration).
* Docker Integration has arrived. Connect to a Docker registry and pull repos into your workspace, or make changes to a Docker container and push it back to Docker Hub. Read the docs for more information.
* Create snapshots of your dev environment in an instant. Snapshots can be shared through a Docker Registry, used as a backup, or to duplicate your dev environment. Read the docs to get started.
* A new version of Nitrous desktop has been released for Windows, Mac, and Linux. [View our support guide and download the new app](http://docs.nitrous.io/v1.0/docs/nitrous-sync).
* Nitrous desktop has had an overhaul. Sync times have been increased, and you now have the option to exclude specified file types.
* Many IDE editor improvements have been added. Split pane, syntax highlighting improvements, and file browser auto refresh are amoung the many new features available.

If you have any questions or suggestions, you can [email us](mailto:support@nitrous.io).

Don't forget to subscribe to our [Blog's RSS Feed](http://feeds.feedburner.com/actionio-updates) to hear about new product releases.
