title: Changelog - May 23, 2014
---

If you haven't noticed some of these updates this month, you haven't been using Nitrous.IO enough.

* IDE improvements have arrived! [Read how you can utilize these new features now](http://blog.nitrous.io/2014/05/13/ide-improvements.html). New features include bracket matching, lines and rulers, code folding, white space trimming, code linting, vim key bindings, comment shortcut (**Cmd + /**), and auto-completion for CSS, XML, HTML and JavaScript.
* [Light and Dark Themes](http://blog.nitrous.io/2014/05/02/new-themes-available-for-web-ide.html) have been added to the Web IDE.
* You can now search within multiple files. Press **Shift + Cmd + F** while in the Web IDE to do this.
* You can now re-arrange tabs within the Web IDE. Simply click and drag tabs in the order of your choice.
* Links in Web IDE chat are now clickable. This can be used to instantly open a file or a URL which a collaborator has shared.
* Clojure has been added to Autoparts. run `parts install clojure` in the terminal to install it, and [read our blog post](http://blog.nitrous.io/2014/05/06/learn-clojure.html) for a overview on using Clojure and Leiningen.
* The Go version for Google App Engine and Exuberant Ctags have been added to Autoparts. Thanks [Ronoaldo!](https://github.com/ronoaldo)
* Elixir has been added to [Autoparts](http://help.nitrous.io/autoparts). Install it by running `parts install elixir` in the terminal.
* Multiple Ruby versions have been added to [Autoparts](http://help.nitrous.io/autoparts). You can utilize different versions by using Chruby (also in Autoparts).
* We've added a Hack on Nitrous.IO Bookmarklet, which allows you to download any Github project directly to your Nitrous box. Read more on our [blog post](http://blog.nitrous.io/2014/05/15/hack-bookmarklet.html)

Follow [@nitrousio](http://www.twitter.com/nitrousio) for more news, or check out our [blog](http://blog.nitrous.io).

If you have any questions or suggestions, feel free to [email us](mailto: support@nitrous.io).
