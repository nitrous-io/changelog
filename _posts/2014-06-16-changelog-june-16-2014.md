title: Changelog - May 16, 2014
---

More updates have arrived. New IDE features have been added, new packages are available, and some big announcements are just around the corner. Stay tuned to [@nitrousio](http://www.twitter.com/nitrousio) for updates and other great news.

* Multiple cursor support has been added to the Web IDE. [Read our blog post](http://blog.nitrous.io/2014/06/04/multiple-cursors-selections.html) for more information on using this feature.
* We've added Quick Find to the Web IDE. Press `Shift + Ctrl + P` to bring up the menu for a fuzzy file search. [Read our docs for more information on usage](http://help.nitrous.io/quick-open/).
* More packages are available in Autoparts. Thanks [Codelion](https://github.com/codelion), [GeertVL](https://github.com/GeertVL) and [Ronoaldo](https://github.com/ronoaldo) for contributing! New packages include Elasticbeanstalk, Google App Engine Java/Go versions, Zeromq, Spidermonkey, and CouchDB.
* Existing packages in Autoparts have been updated. Updated packages include Ruby 2.1.2, PhantomJS 1.9.7, Google App Engine v1.9.5, Heroku Toolbelt 3.8.2, and PHP 5.4.29.

Follow [@nitrousio](http://www.twitter.com/nitrousio) for more news, or check out our [blog](http://blog.nitrous.io).

If you have any questions or suggestions, feel free to [email us](mailto: support@nitrous.io).
