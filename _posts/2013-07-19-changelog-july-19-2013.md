Big changes last few weeks at [@nitrousio](http://www.twitter.com/nitrousio).  Check out some of the awesomeness:

* You can now code locally using your favorite native Mac editor with our [Mac Application](https://www.nitrous.io/mac)
* The [Nitrous.IO Chrome App](https://chrome.google.com/webstore/detail/nitrousio/kcbmakmdbnehgbakmgibcpjpafenmohd?hl=en) is now available in the Chrome Web Store
* Pre-Installed [virtualenv](http://www.virtualenv.org/en/latest/) on all python boxes
* Added option to reconfigure storage and memory resources for existing boxes
* Ruby/Rails boxes now use Rails 4 by default
* Added Find/Replace text options in the Web IDE text editor
* Added more ways to earn resources on the [N2O Bonus Page](https://www.nitrous.io/app#/n2o/bonus)


If you have any questions or suggestions, you can [talk to a human](mailto: support@nitrous.io).

Don't forget to follow us on [Twitter](http://www.twitter.com/nitrousio) and subscribe to our [Updates Blog](http://feeds.feedburner.com/actionio-updates) to hear about new product releases.
