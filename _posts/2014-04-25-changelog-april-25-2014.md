title: Changelog - April 25, 2014
---

Many more improvements have arrived! Follow [@nitrousio](http://www.twitter.com/nitrousio) for more news, or check out our [blog](http://blog.nitrous.io).

* We have introduced a 'Hack' button which allows any developer to start coding on your project repository instantly. [Add a button to your public Github repo now](https://www.nitrous.io/hack).
* The Heartbleed vulnerability was patched. Read more about the fix on our [blog post](http://blog.nitrous.io/2014/04/10/openssl-heartbleed-security-update.html).
* Added an option on the [bonus page](https://www.nitrous.io/app#/n2o/bonus) to disconnect your account from Github and Google. Use this option to connect to a different account.
* Fixed MySQLi compile options. You can now utilize MySQLi instantly when installing PHP5 with [Autoparts](http://help.nitrous.io/autoparts).
* Added many new databases and tools to [Autoparts](http://help.nitrous.io/autoparts). This includes Flex, InfluxDB, LevelDB, libmad, Snappy, Pip, Setuptools, Python 2, Python 3, Bison, Tomcat, Photobuf, and Dart.

If you have any questions or suggestions, you can [talk to a human](mailto: support@nitrous.io).

Don't forget to subscribe to our [Blog's RSS Feed)](http://feeds.feedburner.com/actionio-updates) to hear about new product releases.
