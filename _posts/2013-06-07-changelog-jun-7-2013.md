Stay tuned to [@nitrousio](http://www.twitter.com/nitrousio) for updates.  Here's a look at some improvements we made last week:

* Updated Ruby, NodeJS and Python box templates
* Added additional keyboard shortcuts to IDE
* Colored user cursors in Collaboration mode
* Miscellaenous collaboration mode improvments
* Backend fixes for performance and stability improvements
* Drag and drop files in IDE directory tree
