---

More features have arrived! 

* [Nitrous Desktop](http://www.nitrous.io/mac) has been released for Mac! This will sync data between your Nitrous box and your local computer. You can also enable port forwarding, start/shutdown your boxes, and more. The latest version of [Nitrous Desktop](http://www.nitrous.io/mac) (1.0.3-2) includes bug fixes, as well as a sync notification icon within the menu bar.
* PHP is now available! Read about it more on our [blog post](http://blog.nitrous.io/2014/02/12/announcing-php-support.html). If you are looking to utilize frameworks such as Laravel, you can do so with Composer (also available with [Autoparts](http://help.nitrous.io/autoparts)).
* [WordPress](http://help.nitrous.io/wordpress) has been added to [Autoparts](http://help.nitrous.io/autoparts). You can now setup a WordPress site with a MySQL database pre-configured in seconds.
* Apache2 has arrived! Install and start it with [Autoparts](http://help.nitrous.io/autoparts).
* A Status page has been added for all Nitrous services. Check to see any maintenance or server issues on [http://status.nitrous.io](http://status.nitrous.io)
* A warning message now appears for situations where the connection within the Web IDE is lost.
* Get more free N2O! Check out the [bonus page](https://www.nitrous.io/app#/n2o/bonus) to find a survey to tell us how you work. Not only will you get a bonus of 25 N2O, but we may also add that feature you have always been wanting to see.

If you have any questions or suggestions, you can [talk to a human](mailto: support@nitrous.io).

Don't forget to follow us on [Twitter](http://www.twitter.com/nitrousio) and subscribe to our [Updates Blog](http://feeds.feedburner.com/actionio-updates) to hear about new product releases.
