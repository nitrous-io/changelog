title: Changelog - September 27, 2013
---

Many more improvements have arrived! Follow [@nitrousio](http://www.twitter.com/nitrousio) for more news, or check out our [blog](http://blog.nitrous.io).

* Introduced Autoparts, a package manager that allows you to install databases, languages, and other tools on your Nitrous.IO box. Read more about it on our [blog post](http://blog.nitrous.io/2013/09/18/introducing-autoparts-for-nitrous-io.html).
* Added Meteor support. Ensure you have [Autoparts installed](http://help.nitrous.io/autoparts/), and install with the command `parts install meteor`.
* You can now install databases locally. MySQL, PostgreSQL, Memcached, Redis, and MongoDB are all available within Autoparts. Read the [help guide]((http://help.nitrous.io/autoparts/) for more information on usage.
* Opened up ports 3000 - 9999 for previewing your app. View the [help guide](http://help.nitrous.io/preview/) for usage.
* All new boxes on Nitrous.IO will run the `Bran` stack. Bran introduces support for inotify, which is used by popular tools such as guard, fswatch, and Sass. Take a look at our [upgrade guide](http://help.nitrous.io/upgrade-box/) for more information on this.

If you have any questions or suggestions, you can [talk to a human](mailto: support@nitrous.io).

Don't forget to follow us on [Twitter](http://www.twitter.com/nitrousio) and subscribe to our [Updates Blog](http://feeds.feedburner.com/actionio-updates) to hear about new product releases.
